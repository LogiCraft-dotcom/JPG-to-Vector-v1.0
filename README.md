# Image to Vector EPS Converter 🎨
*Developed by Logicraft*

A lightweight desktop application that instantly converts JPG, PNG, and SVG files into high-quality, editable EPS 10 vector formats. 

### ✨ Features
* **Multi-Format Support:** Import `.jpg`, `.png`, and `.svg` files.
* **EPS 10 Output:** Guarantees broad compatibility with Adobe Illustrator, CorelDRAW, and other vector editing software.
* **Offline Processing:** Everything runs locally on your machine—no internet connection required.

### 🚀 Download and Install

**[⬇️ Download the latest setup file version here](https://github.com/LogiCraft-dotcom/JPG-to-Vector-v1.0/releases/download/JPGtoVector/BatchImageVectorConverter.zip))**

1. Download the `setup file` file from the link above.
2. Open Dist Folder.
3. Double-click the file to launch the converter.
4. Select your input image and choose your output destination.

### 💻 How to Use
1. Click **"Browse"** to select your JPG, PNG, or SVG file.
2. Select the output directory for your new EPS file.
3. Click **"Convert to EPS 10"**.
4. Your vector file is ready to use!
